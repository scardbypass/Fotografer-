# Android Uploader

Target: tablet Android + Canon EOS 600D via USB OTG.

## Sudah tersedia
- USB Host detection
- UI landscape
- HTTPS multipart uploader
- struktur event + upload token

## Berikutnya
Implementasikan PTP event listener Canon (ObjectAdded), download JPEG baru ke cache, preview fullscreen, persistent upload queue, dan pengaturan URL/token.

Canon 600D harus dites pada perangkat fisik sebelum kompatibilitas PTP dinyatakan final.
